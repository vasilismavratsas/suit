# ExoSuit Tile CAD

A Vite + React web app for designing a next-generation space suit exoskeleton made from repeated interlocking titanium hexagonal and pentagonal tiles.

## Features

- Parametric tile generation for torso, arm, leg, and helmet suit sections
- Hexagonal load-shell tiles with pentagonal seam, crown, and flexion-zone relief tiles
- Connector visualization at every tile edge
- Interactive tile inspector for material, thickness, rotation, and shape overrides
- Mass, connector, and bill-of-material metrics
- Exportable JSON model for CAD/manufacturing handoff
- Interactive 3D titanium tile model with drag-to-rotate, scroll-to-zoom, and click-to-select controls
- Multi-surface assembly modes for flat panels, arm/leg tubes, torso shells, and helmet domes
- Adjustable wrap coverage for linking tile fields around cylindrical or elliptical suit sections

## Run locally

```bash
npm install
npm run dev
```
